Detailed Description

template<typename MessageType, size_t kCapacity>
class OsQueue< MessageType, kCapacity >

Fixed-capacity, eager-init MPMC queue of trivially-copyable items.

Template Parameters
MessageTypeElement type (must be trivially copyable; passed by value through the underlying queue).
kCapacityMaximum number of pending elements.
