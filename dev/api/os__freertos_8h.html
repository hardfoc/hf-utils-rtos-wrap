Detailed Description

FreeRTOS backend for the generic OS abstraction.

Included only by OsAbstraction.h when HF_RTOS_FREERTOS is selected. Do not include this header directly.

Supported flavors

Flavor Kernel headers Task affinity Critical section
Vanilla (CubeMX, ARM_CMx ports) flat FreeRTOS.h single core ISR masking
ESP-IDF SMP freertos/FreeRTOS.h pinned-to-core spinlock (portMUX_TYPE)

Both are detected here, at the port layer. A consumer build must not force-include a compatibility header or synthesize a freertos/ include directory to satisfy this backend.

See also
os/README.md

Wait for event bits.

Parameters
optionOS_AND (all of flags) or OS_OR (any of them), optionally OR-ed with OS_EVENT_CLEAR to clear flags when the wait is satisfied. Without OS_EVENT_CLEAR no bit is cleared.
Returns
OS_SUCCESS when the condition was met; 1 on timeout. actual receives the bits seen (before any clear) either way.
