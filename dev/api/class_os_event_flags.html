Wait for bits to be set per mode, up to timeout_ms.

Bits are NOT cleared on return.

Parameters
[in]bitsBit mask to wait for.
[in]modeANY or ALL semantics.
[in]timeout_msMax wait in ms; pass UINT32_MAX to wait forever.
[out]actual_bitsBits seen at wake-time (for ANY mode caller can tell which fired).
Returns
true on success (bits satisfied), false on timeout.
